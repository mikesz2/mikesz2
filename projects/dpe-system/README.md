# 🛡️ DPE System — Case de Portfólio

> Esta página é pública para apresentar o projeto sem expor o componente proprietário DPE Command.

## Contexto

O DPE System foi criado para centralizar operações de uma corporação virtual no Habbo em uma única aplicação web.

O sistema precisava substituir diversos controles manuais por fluxos rastreáveis, com permissões, histórico, auditoria e automação.

## Principais módulos

- autenticação e níveis de acesso;
- membros, patentes e divisões;
- turnos e contabilização de tempo;
- promoção, demissão, aulas e requisições;
- histórico de perfil;
- documentos e comunicação interna;
- notificações;
- rede social interna;
- rankings e condecorações;
- segurança, auditoria e saúde do sistema.

## Stack

Node.js · Express · Prisma ORM · SQLite · JavaScript · HTML/CSS · JWT · Git/GitHub · Linux
